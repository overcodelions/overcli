# docs/

Supporting documentation and media for the Overcli project.

- **[`guide/`](guide/README.md)** — the user guide: getting started, concepts, chats & agents, flows, workers, services and more.

- **[`../deploy/docs/`](../deploy/docs/README.md)** — the org server (overgo) docs: using workers, managing them, running the server, the security model. The server also serves these at `/docs`.

- **`screenshots/`** — PNG captures referenced by the top-level `README.md`. See [`screenshots/README.md`](screenshots/README.md) for the expected files and capture recipe.

For architecture and how a turn flows, see the **Architecture** section in the top-level [`README.md`](../README.md#architecture). Contributor setup lives in [`CONTRIBUTING.md`](../CONTRIBUTING.md).
